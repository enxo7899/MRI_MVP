🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Service won't start:
   → docker-compose logs <service-name>
   → docker-compose restart <service-name>

   Port already in use:
   → sudo lsof -i :80
   → Change port in docker-compose.yml

   Out of memory:
   → Docker Desktop → Settings → Resources → 8GB+

   Clean restart:
   → docker-compose down -v
   → docker-compose up -d --build
